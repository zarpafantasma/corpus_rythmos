## The Core Idea (TL;DR)

RTM proposes that across all complex systems — from quantum fields to economies — the relationship between **time** (τ) and **scale** (L) follows:

**T ∝ L^α**

The exponent **α** is not a fitting parameter. It is a **structural invariant** that classifies the transport mechanism:

| α Value | Transport Class | Examples |
|---------|-----------------|----------|
| α = 1 | Ballistic | Earthquakes, sound propagation |
| α = 2 | Diffusive | Heat conduction, random walks |
| α = 3 | Lévy/Richardson | Ocean turbulence, epidemic spread |
| α > 2.5 | Coherent/Organized | Hurricanes, mature vortices, blocking patterns |

**When α changes abruptly → a phase transition is occurring.**

This single principle unifies phenomena from black holes to brain states to tornado formation.
